# Outlaw Fence Co — agricultural and livestock fencing, Spokane County WA

Rendered static site. Source, content and build scripts live in the Simply Digital repo; only the
built output is published here.

**This is a preview build.** Every page carries `noindex,nofollow` and `robots.txt` disallows all
crawling, because launch requirements are still open. See the client project for the blocker list.
The site will not appear in search until those clear and it is rebuilt.

Built with `scripts/sites/build_fence_sites.py`. No trackers, no external requests, no web fonts.
